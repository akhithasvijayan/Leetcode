# 🧠 Leetcode — DSA Practice

This repo is where I practice Data Structures & Algorithms (DSA) by solving problems on [LeetCode](https://leetcode.com/) and pushing my solutions here as I go.

## 🎯 Goal

I'm using this space to:
- Sharpen my problem-solving and DSA fundamentals (arrays, strings, pointers, searching, sorting, linked lists, stacks/queues, and more)
- Build consistency by solving problems regularly and tracking my progress over time
- Improve my overall programming and coding-interview skills

## 📈 About this repo

This is an **evergrowing, personal practice log** — new solutions get added as I solve more problems, and older ones may get revisited and rewritten as my approach improves. It's less about a polished, organized library and more about consistent practice, so expect it to keep growing over time.

## 🧱 Language

- **Python** — solutions are written as a `class Solution`, matching LeetCode's submission format, so they can be pasted directly into the LeetCode editor.
